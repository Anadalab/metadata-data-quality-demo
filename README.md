# Metadata & Data Quality Demo

¡Hola! 👋 Soy Ana, y este es un pequeño proyecto que simula cómo gestiono y valido datos en un entorno profesional.  

En este repositorio encontrarás ejemplos de cómo realizar **validaciones de calidad de datos**, manejar **metadatos** y generar **métricas útiles para decisiones de negocio**. Todo está inspirado en tareas que realizo en proyectos reales de Data Governance y QA funcional.  

---

## Qué encontrarás aquí

- `data_quality_checks.sql`: Scripts de validación de datos para detectar nulos, duplicados, errores de integridad y más.
- `metadata_dictionary.md`: Diccionario de metadatos de ejemplo, que documenta cómo organizamos la información.
- `kpi_reports.sql`: Cálculo de métricas y KPIs para evaluar la calidad del dato.
- `sample_data/`: Datos de ejemplo para poder probar los scripts y entender cómo funciona todo.

---

## Herramientas y tecnologías

- **SQL** para consultas y validaciones.
- **Python** para automatizaciones (opcional).
- **Markdown** para documentación clara y visual.
- Metodología **Agile/Scrum** aplicada a la gestión de datos.

---

## Objetivo del proyecto

Este repositorio no solo sirve para practicar SQL o análisis de datos.  
Mi intención es **mostrar cómo aplico un enfoque funcional y práctico en proyectos reales**, asegurando que los datos sean confiables, consistentes y listos para la toma de decisiones.
